#  MATLAB Image Processing GUI

##  Description
This project is a MATLAB-based graphical user interface (GUI) for image processing.  
It allows users to load images and apply various processing operations interactively.

---

##  Features
- Intensity profile
- Histogram analysis
- Noise filtering
- Image rotation
- Image inversion
- Gray level scanning
- Block extraction
