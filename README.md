#  MATLAB Image Processing GUI

##  Description
Designed and implemented an interactive MATLAB-based image processing system with GUI, integrating filtering, histogram analysis, and computer vision techniques.
---

##  Features
- Intensity profile
- Histogram analysis
- Noise filtering
- Image rotation
- Image inversion
- Gray level scanning
- Block extraction
